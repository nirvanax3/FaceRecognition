**FaceRecognition**
A simple face‑recognition application using Python.

Description
This project provides a basic setup to:

Encode known faces from images.

Recognize faces in live camera feed or images.

Label recognized faces and optionally mark unknowns.

Features

Face encoding generation.

Real‑time face detection and recognition.

Flexible to add new people by adding their images and regenerating encodings.

Minimal dependencies and simple workflow
